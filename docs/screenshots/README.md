# Screenshots

Drop the PNG/JPG screenshots referenced from the project's README files
into this folder.

Recommended captures (≈ 1200 × 800 px each, light theme for clarity):

| File name                       | What to capture                                              |
|---------------------------------|--------------------------------------------------------------|
|`rpmb_welcome.png`               | Welcome page of the App                                      |  
| `plot_builder_main.png`         | Plot Builder main view with 2–3 spectra and annotated peaks  |
| `match_search_main.png`         | Match Search with 2–3 tabs open and the tree on the left     |
| `match_search_fitwindow.png`    | A Fit window showing peak fitting + match analysis           |
| `auto_identify.png`             | The auto-identification results dialog with Top-10 hits      |
| `pdf_report.png`                | One page of a generated PDF report (page 2 or 3)             |
| `splash.png`                    | The splash dialog at startup (optional, nice on the README)  |

> Tip: enable the light theme (View > Theme > Light) before taking the
> screenshots, even if you usually work in dark mode — they read better
> on most browsers.
